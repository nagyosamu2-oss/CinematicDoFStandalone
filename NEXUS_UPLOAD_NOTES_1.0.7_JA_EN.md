# Nexus upload notes — CinematicDoFStandalone 1.0.7

## Files

- `CinematicDoFStandalone-1.0.7-Full-MO2.zip` — main file for new installations; includes the bundled INI defaults.
- `CinematicDoFStandalone-1.0.7-Update-Merge-MO2.zip` — optional update file; excludes the INI so saved settings are retained. MO2 users must choose Merge, not Replace.
- `CinematicDoFStandalone-1.0.7-Source.zip` — corresponding source and bundled dependency source snapshot.
- `SHA256SUMS.txt` — upload verification hashes.

## Suggested Nexus labels

- Full package: Main File

## Short description

Standalone cinematic depth of field for Skyrim SE/AE with target tracking, dialogue focus, shaped bokeh, diffraction starburst, hair blending, and a bilingual in-game UI. Community Shaders is optional.
